# 用户整理工作台（个人版）

把自己名下的私域客户整理成一张能用的工作台：分层、待办、开课复盘、聊天分析、打标签。

**每个人的数据各自拉，互不相通。** 页面在你本机生成，不上传任何数据。

## 快速开始

1. 下载本仓库（Code → Download ZIP）并解压
2. 双击启动文件 —— **macOS 用 `启动.command`，Windows 用 `启动.bat`**
3. 浏览器自动打开 `http://127.0.0.1:8901`
4. 贴上你自己的 CRM 凭证（`jsu_` 开头），点「开始生成我的工作台」
5. 等 3–8 分钟，自动进入工作台

> macOS 第一次双击若提示"来自身份不明的开发者"，在文件上 **右键 → 打开** 一次即可。
> Windows 若提示缺少 Python，装一次 python.org 的 Windows 版，安装时勾选 **Add python.exe to PATH**。

## 需要什么

| 系统 | 启动文件 | Python |
|---|---|---|
| macOS | `启动.command` | 系统自带，无需安装 |
| Windows | `启动.bat` | 需装一次 [python.org](https://www.python.org/downloads/) 版本 |

都要能访问 `https://jiasujiaoyu.cn`（公司网络可能需要连 VPN）。

## 凭证

找管理员要，**一人一份**。凭证只存在你本机 `~/.workbuddy_token`。

## 页面上有什么

| 页面 | 干什么 |
|---|---|
| 总览 | 客户规模、消费分档、今天先干哪几件 |
| 今天做什么 | 只列今天真要做的事，点开就是名单 |
| 客户池 | 按学习/消费/关系/沟通四层筛，点开看档案 |
| 四层分层 | 学习层、关系层、消费层、沟通层，每层可下钻 |
| 开课复盘 | 每场课的到课、新老、留存流失，按月汇总 |
| 开课锁定 | 高客单课开课前，锁定 A/B 类候选学员 |
| 打标签 | 按条件圈人，导出企微标签清单 |
| 聊天分析 | 会话存档里的真实对话质量（需另配数据） |
| 真新客 / 未付款 / 留存预警 | 三张固定名单 |

## 可选数据文件

放到同目录后重新生成，功能更全：

| 文件 | 作用 |
|---|---|
| `课程权限_已购.csv` | 已购课程明细，用于消费补算和开课锁定的品类排除 |
| `开课节点.csv` | 复盘场次（格式见 `示例数据/`） |
| `高客单课程.csv` | 高客单课程表，可自行增删（已在包内） |

## Windows 用户

双击 **启动.bat** 就行。

如果手动来：

```
python 壳服务.py
```

然后浏览器打开 `http://127.0.0.1:8901`。停止服务：任务管理器结束 python.exe，或命令行 `taskkill /IM python.exe /F`。

## 常见问题

**一直转圈**：数据量大，6,000 客户约 3–8 分钟。

**生成失败**：页面会显示日志，截图给管理员。

**换凭证**：删掉 `~/.workbuddy_token` 再打开首页。

**停服务**：`pkill -f 壳服务.py`

## 说明

本项目只做数据整理与呈现，不含任何客户原始数据；所有凭证与数据都留在使用者本机。
